# Evidence

The record behind `PROCESS.md`: one folder per episode it cites (an
experiment, a correction, a measurement), named `YYYY-MM-DD-<slug>/`.

Capture an episode when it happens, before the state is gone; don't
reconstruct it later. Each folder's `README.md` says, in this order:

1. **The question** the episode answers.
2. **What happened**, with links to the commits.
3. **What's here**: the files in the folder.
4. **How it was made**, so it could be made again.
5. **Things to know when judging it**: its limits, and anything that would
   mislead someone reading it cold.

Screenshots kept here come from `scripts/shot.mjs`, named
`<state>-mobile.png` and `<state>-desktop.png`.
